# Obsidian Vault — база знаний проектов

> **Открой первым:** [[Старт_Агента]] — точка входа для агентов.

## Что здесь

Это Obsidian vault для многоагентной разработки. На верхнем уровне находятся общая область, AgentSystem и прикладные проекты; внутри каждого проекта материалы разделены по аудитории.

```text
00_Общее/     — общая навигация, правила, промпты, шаблоны и межпроектные доказательства
Finance/
Focus/
AgentSystem/
RocketFlow/
```

В каждом проекте:

- `01_Человеку/` — навигация, обзор, архитектура, дизайн, решения, глоссарий, источники и читаемые доказательства;
- `02_Агентам/` — задачи, роли, промпты, регламенты, пакеты контекста, ревью и машинные артефакты.

## Быстрый старт

1. Открой [[Старт_Агента]] — все правила, карта vault, навигация
2. Открой [[MOC_Все_Проекты]] — хаб всех проектов
3. Выбери проект → открой его MOC-карту

## Принципы

- Русский язык основной. Английский допустим только для точных технических имён; редкий термин при первом употреблении кратко объясняется по-русски в скобках.

- Код не копировать — ссылки на файлы репозитория

- Факты с источниками и доказательствами
