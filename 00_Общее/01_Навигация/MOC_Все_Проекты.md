# MOC — Все проекты

Верхнеуровневая карта vault. Каждый проект живёт в собственном корне и разделён на материалы для человека и материалы для агента.

## Активные проекты

### [[RocketFlow]]
- **Тип:** планировщик задач и целей
- **Стек:** Java/Spring Boot + React + Android/Kotlin + PostgreSQL
- **Стадия:** MVP3 (упрощение и полировка)
- **Под-MOC:** [[MOC_Бэкенд]], [[MOC_Веб]], [[MOC_Android]], [[MOC_DevOps]]

### [[Finance]]
- **Тип:** ручной учёт личных и семейных финансов
- **Стек:** Python/FastAPI + React PWA + Kotlin Android + PostgreSQL
- **Стадия:** Production MVP functional GO (2026-05-19)
- **Под-MOC:** [[MOC_Finance]]

### [[Focus]]
- **Тип:** планировщик задач и целей с green/red механикой
- **Стек:** Java 21/Spring Boot 3.4 + React 18 + Kotlin Android + PostgreSQL
- **Стадия:** Активная разработка + QA тестирование (253 кейса)
- **Под-MOC:** [[MOC_Focus]]

### [[AgentSystem]]
- **Тип:** общая система и коллекция агентов
- **Стадия:** первый действующий агент — [[AgentSystem/01_Человеку/Продукт/Poruchik/00_MOC|Poruchik]]; актуальный статус MVP0 — [[18_Сводка_приёмки_MVP0_2026-09-12]]
- **Платформа:** OpenClaw (оркестрация) + n8n (интеграция, пять инструментов напоминаний и рабочие процессы) + Gateway + TaskCore + PostgreSQL
- **Под-MOC:** [[MOC_AgentSystem]]
- **Агент:** [[AgentSystem/01_Человеку/Продукт/Poruchik/00_MOC|Poruchik]]

## Как добавить новый проект

1. Создать корень `ИмяПроекта/` и стандартные подпапки из таблицы выше.
2. Создать главную заметку проекта в `ИмяПроекта/01_Человеку/00_Навигация/`.
3. Добавить ссылку на проект в секцию «Активные проекты» этой карты
4. Создать MOC-карту проекта рядом с главной заметкой.
5. Рабочие материалы раскладывать по аудитории, не создавая новых категорийных корней vault.
