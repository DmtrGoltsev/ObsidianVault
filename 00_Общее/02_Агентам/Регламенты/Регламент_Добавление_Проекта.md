# Регламент: Добавление нового проекта в Obsidian vault

При появлении нового проекта агент обязан выполнить шаги ниже. Vault: `%USERPROFILE%\Documents\ObsidianVault`.

## Шаг 1. Создать проектные подпапки

```powershell
$v = "$env:USERPROFILE\Documents\ObsidianVault"
$p = "ИмяПроекта"
@(
    "$v\$p\01_Человеку\00_Навигация",
    "$v\$p\01_Человеку\Обзор",
    "$v\$p\01_Человеку\Архитектура",
    "$v\$p\01_Человеку\Дизайн",
    "$v\$p\01_Человеку\Решения",
    "$v\$p\01_Человеку\Глоссарий",
    "$v\$p\01_Человеку\Источники",
    "$v\$p\01_Человеку\Доказательства",
    "$v\$p\02_Агентам\Задачи",
    "$v\$p\02_Агентам\Роли",
    "$v\$p\02_Агентам\Промпты",
    "$v\$p\02_Агентам\Регламенты",
    "$v\$p\02_Агентам\Пакеты_контекста",
    "$v\$p\02_Агентам\Ревью",
    "$v\$p\02_Агентам\Артефакты"
) | ForEach-Object { New-Item -ItemType Directory -Path $_ -Force }
```

## Шаг 2. Создать главную заметку проекта

Файл: `ИмяПроекта/01_Человеку/00_Навигация/ИмяПроекта.md`

Использовать [[Шаблон_Проект]]. Заполнить: id, цель, стек, статус, команда, окружения, риски. Добавить `[[MOC_Все_Проекты]]`.

## Шаг 3. Создать MOC-карту проекта

Файл: `ИмяПроекта/01_Человеку/00_Навигация/MOC_ИмяПроекта.md`, рядом с главной заметкой проекта.

## Шаг 4. Зарегистрировать проект в MOC_Все_Проекты

Открыть `00_Общее/01_Навигация/MOC_Все_Проекты.md`, добавить в секцию «Активные проекты».

## Шаг 5. Создать задачи (опционально)

Файлы в `ИмяПроекта/02_Агентам/Задачи/`. Использовать [[Шаблон_Задача]].

## Шаг 6. Создать пакеты контекста (опционально)

Файлы в `ИмяПроекта/02_Агентам/Пакеты_контекста/`. Использовать [[Шаблон_Пакет_Контекста]].

## Шаг 7. Добавить ADR (опционально)

Файлы в `ИмяПроекта/01_Человеку/Решения/`. Использовать [[Шаблон_Решение]].

## Шаг 8. Пополнить глоссарий (опционально)

Файлы в `ИмяПроекта/01_Человеку/Глоссарий/`. Использовать [[Шаблон_Термин]].

## Шаг 9. Создать источники (опционально)

Файлы в `ИмяПроекта/01_Человеку/Источники/`. Использовать [[Шаблон_Источник]].

## Шаг 10. Создать агентов (опционально)

Файлы в `ИмяПроекта/02_Агентам/Роли/`. Использовать [[Шаблон_Агент]].

## Шаг 11. Создать доказательства (опционально)

Файлы в `ИмяПроекта/01_Человеку/Доказательства/`. Использовать [[Шаблон_Доказательство]].

## Правила

- Язык: русский (тех. названия — английский)
- YAML frontmatter обязателен
- Код не копировать — ссылки на файлы репозитория
- `[[Ссылки]]` на связанные заметки
- Секреты не сохранять
- Уверенность без источников — `низкая`

## Шаг 12. Инициализировать Git (опционально)

Если проект требует Git-репозитория — см. [[Регламент_GitHub_для_Агентов]], секция 6 «Создание нового Git-репозитория для проекта».
