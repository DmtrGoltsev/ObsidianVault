# Границы и решения по OpenClaw

## Цель MVP

Разместить OpenClaw рядом с n8n на рабочем виртуальном сервере и получить личного Telegram-помощника, который:

- понимает свободную речь;
- помнит явно сохранённые факты;
- использует DeepSeek;
- управляет напоминаниями через защищённые сценарии n8n;
- не получает опасных общих полномочий.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Где работает OpenClaw | Только на рабочем виртуальном сервере; на локальный компьютер не устанавливается |
| Канал общения | Тот же Telegram-бот и один разрешённый личный чат |
| Получение сообщений | Долгий опрос Telegram, без публичного входящего адреса OpenClaw |
| Языковая модель | DeepSeek |
| Разговор и контекст | OpenClaw |
| Строгие действия и правила | n8n |
| Надёжное состояние задач | PostgreSQL |
| Смысловая долговременная память | Markdown |
| Векторная база | Не входит в MVP; добавляется только при доказанной необходимости |
| Групповые чаты | Отключены |
| Панель управления | Только через SSH-туннель |
| Расширение сервера | Пока не выполняется |

## Что входит в первый выпуск

- обычный диалог через Telegram;
- память по явной просьбе «запомни»;
- создание напоминания;
- просмотр напоминаний;
- перенос напоминания;
- отмена напоминания;
- кнопки подтверждения и отмены;
- плановая отправка уведомлений силами n8n;
- отказ неизвестному отправителю.

## Что не входит

- произвольная командная строка;
- общий доступ к сети и файловой системе;
- браузерное управление;
- самостоятельная установка новых расширений;
- платежи и разрушительные операции;
- работа в групповых чатах;
- перенос старой истории разговоров;
- локальная установка OpenClaw.

## Ограничения пилота

OpenClaw получает не более 512 МБ памяти, половины ядра процессора и одной одновременно обрабатываемой сессии. Это осознанный режим до расширения сервера.

## Условие принятия

Целевое решение становится фактическим только после полной проверки Telegram, DeepSeek, памяти, инструментов, плановой отправки, ограничений ресурсов и отсутствия лишних публичных портов.
