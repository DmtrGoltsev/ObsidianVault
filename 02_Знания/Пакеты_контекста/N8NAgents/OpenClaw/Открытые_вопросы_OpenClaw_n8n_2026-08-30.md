# Открытые вопросы OpenClaw

## Уже решено

- OpenClaw устанавливается только на рабочий сервер.
- Используется тот же Telegram-бот и один личный чат.
- Модель — DeepSeek.
- OpenClaw получает сообщения долгим опросом.
- n8n остаётся единственным контуром строгих действий.
- PostgreSQL хранит задачи и операции, Markdown — смысловую память.
- Векторная база не входит в MVP.
- Панель OpenClaw не публикуется в интернет.
- Ресурсы ограничены 512 МБ памяти и половиной ядра.

## Требует итоговой проверки

- OpenClaw является единственным получателем сообщений Telegram.
- Память сохраняется после перезапуска.
- DeepSeek видит только разрешённые инструменты.
- Кнопки подтверждения и отмены работают без участия модели.
- Создание, список, перенос и отмена напоминаний проходят полный путь через n8n.
- Плановое уведомление приходит независимо от OpenClaw.
- Неизвестный отправитель получает отказ.
- n8n, PostgreSQL и Caddy не ухудшили работу после установки.

## Отложено после MVP

- расширение виртуального сервера;
- векторный поиск;
- дополнительные мессенджеры;
- новые внешние API;
- импорт старой истории разговоров;
- внешнее хранилище резервных копий.
