# Эксплуатация OpenClaw

## Порядок развёртывания

1. Зафиксировать состояние n8n, PostgreSQL, Caddy и Telegram.
2. Проверить контрольную сумму пакета и точный образ OpenClaw.
3. Установить OpenClaw без переключения Telegram.
4. Проверить конфигурацию, расширения и DeepSeek.
5. Проверить ограничения контейнера и отсутствие публичных портов.
6. Подготовить автоматический возврат к прежнему входу n8n.
7. Остановить прежний входящий сценарий n8n.
8. Включить получение сообщений OpenClaw.
9. Выполнить реальные проверки в Telegram.
10. После успеха включить плановые отправители и обновить Obsidian.

## Ограничения ресурсов

| Ресурс | Ограничение MVP |
|---|---|
| Оперативная память | 512 МБ |
| Процессор | 0,5 ядра |
| Число процессов | 128 |
| Одновременные диалоги | один |
| Публичные порты | отсутствуют |

## Наблюдение

Проверяются:

- состояние контейнера;
- перезапуски и нехватка памяти;
- время ответа DeepSeek;
- ошибки инструментов;
- число активных и просроченных напоминаний;
- единственный получатель сообщений Telegram;
- отсутствие новых внешних портов.

## Откат

При ошибке после переключения:

1. остановить OpenClaw;
2. вернуть прежний вход Telegram в n8n;
3. включить прежний сценарий;
4. проверить одно сообщение;
5. сохранить базу и историю для диагностики.

Откат не должен удалять PostgreSQL, тома Docker, задачи или ключ шифрования n8n.

## Обновление

Новая версия OpenClaw сначала проверяется по точной контрольной сумме и запускается без Telegram. Автоматическое обновление без проверки запрещено.
