## Действия владельца

1. Выбрать постоянное закрытое место для ключевого хранилища Android вне репозитория и резервную копию этого хранилища.
2. Разрешить создание нового ключа подписи либо указать уже существующий ключ. Пароли и сам закрытый ключ в чат и репозиторий не передавать.
3. Подтвердить подпись именно проверенного среза кода и установку на выбранный телефон.
4. На телефоне один раз разрешить установку из доверенного локального источника и установить подписанный APK.
5. Открыть приглашение владельца и пройти первичное подключение.

## Автоматические действия после разрешения владельца

1. Собрать вариант `release` из закреплённого коммита с ключом, подключённым только через локальные защищённые параметры.
2. Проверить подпись командой `apksigner verify --verbose --print-certs`.
3. Рассчитать и сохранить SHA-256 уже подписанного APK. Его сумма будет отличаться от суммы неподписанного файла.
4. Убедиться, что имя пакета — `com.poruchik.app`, минимальный API — 26, целевой API — 34, а вариант не отладочный.
5. Установить APK только после отдельного подтверждения владельца.

- приложение запускается без аварийного завершения;
- ссылка приглашения открывает Poruchik;
- неизвестный или изменённый SSH-отпечаток отклоняется;
- после верного приглашения создаётся локальный ключ и поднимается туннель;
- внешний HTTP не открывается, рабочий обмен идёт только через `127.0.0.1` и SSH;
- список задач и карточка открываются;
- без сети ранее полученные данные читаются, безопасное изменение попадает в очередь;

- текстовая и голосовая команды требуют подтверждения распознанного текста;
