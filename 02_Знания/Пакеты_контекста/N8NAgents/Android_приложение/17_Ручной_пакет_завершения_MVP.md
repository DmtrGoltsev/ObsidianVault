# Poruchik — ручной пакет завершения MVP

Ниже собраны только действия, которые нельзя достоверно завершить без владельца или физического устройства. Их следует пройти одной пачкой после автоматического завершения серверной части.

- [x] В Firebase создано Android-приложение `com.poruchik.app`; `google-services.json` проверен, исключён из Git и использован при сборке.
- [x] Создана отдельная минимально привилегированная служебная учётная запись FCM; её JSON размещён на VPS как `/opt/poruchik/secrets/firebase/service-account.json` с доступом только `root` и системной группы ядра задач. Секрет не помещался в чат, репозиторий или документацию.
- [x] Создан постоянный ключ подписи Android в `C:\BackUp\Poruchik-Signing`; пароль вводился владельцем локально и не передавался агенту.
- [x] APK с Firebase подписан, подпись и контрольная сумма проверены; владелец установил его на физический телефон.
- [x] На физическом OnePlus 10T автоматически доказан защищённый транспорт IPv6 → TLS 1.3 → SSH на общем порту `443`; временное диагностическое приложение удалено, данные основного приложения не изменялись.
- [ ] Ввести пароль постоянного ключа подписи и установить поверх текущего приложения окончательный APK с IPv6-маршрутом.
- [ ] Подключить второго пользователя по отдельному приглашению для проверки назначения, ограничений прав и приватности личных задач.
- [ ] После установки обновления получить ровно одно новое IPv6-приглашение владельца из Telegram и завершить регистрацию телефона через SSH.
- [ ] Пройти оставшуюся физическую сквозную проверку: SSH-туннель, список и карточка задач, работа без сети, текст, голос, подтверждение риска, передача задачи, Markdown и push-уведомление.

Отдельная задача после подтверждения нового минимального ключа: удалить в Google Cloud старый ключ широкой служебной учётной записи `firebase-adminsdk-fbsvc`. Это отзыв облачного секрета и выполняется только после явного подтверждения владельца.

Критерий завершения: все пункты отмечены, подписанный APK и его SHA-256 зафиксированы, физическая сквозная проверка имеет результат `PASS`, а [[16_Манифест_текущего_выпуска_2026-09-01]] обновлён по факту.

Серверная Wave 4, установка плагина OpenClaw `0.2.0`, активация двух процессов n8n и автоматическая проверка всех тринадцати инструментов уже завершены. Повторять их в ручном пакете не требуется.
