# Poruchik — ручной пакет завершения MVP

Ниже собраны только действия, которые нельзя достоверно завершить без владельца или физического устройства. Их следует пройти одной пачкой после автоматического завершения серверной части.

- [ ] Создать в Firebase Android-приложение с точным идентификатором `com.poruchik.app` и передать файл `google-services.json` для помещения только в локальный путь `C:\Users\style\Documents\Codex\Poruchik\app\google-services.json`. Этот файл не должен попасть в коммит.
- [ ] Создать отдельную служебную учётную запись Firebase с правом отправки сообщений FCM и через защищённый канал поместить её JSON-файл на VPS как `/opt/poruchik/secrets/firebase/service-account.json` с доступом только владельцу. Сервер ожидает в нём стандартные поля `project_id`, `client_email`, `private_key` и `token_uri`; значение ключа не помещать в чат, репозиторий или документацию.
- [ ] Выбрать постоянный ключ подписи Android и место его хранения с отдельной резервной копией; сам ключ и пароли не передавать агенту.
- [ ] Разрешить подпись проверенного APK, установить его на физический телефон и выдать только необходимые Android-разрешения.
- [ ] Подключить второго пользователя по отдельному приглашению для проверки назначения, ограничений прав и приватности личных задач.
- [ ] Пройти физическую сквозную проверку: приглашение, SSH-туннель, список и карточка задач, работа без сети, текст, голос, подтверждение риска, передача задачи, Markdown и push-уведомление.

Критерий завершения: все пункты отмечены, подписанный APK и его SHA-256 зафиксированы, физическая сквозная проверка имеет результат `PASS`, а [[16_Манифест_текущего_выпуска_2026-09-01]] обновлён по факту.

Серверная Wave 4, установка плагина OpenClaw `0.2.0`, активация двух процессов n8n и автоматическая проверка всех тринадцати инструментов уже завершены. Повторять их в ручном пакете не требуется.
