# Матрица совместимости N8NAgents — 2026-08-26

## Назначение и границы

Это проектная baseline-матрица для подготовки архитектуры. Она не является evidence фактической установки: VPS discovery остаётся `BLOCKED-EXTERNAL`, а server mutations не начаты. Не содержит секретов, доменов, IP, токенов и персональных идентификаторов.

`UNVERIFIED` означает: утверждение ещё не подтверждено проверкой конкретной установленной версии, runtime или внешнего API; его нельзя считать разрешением на deployment без соответствующего live-check.

## Security и data-lifecycle controls

| Контроль | Архитектурное требование | Evidence перед production |
|---|---|---|
| SSRF | Включить и проверить защиту от SSRF в соответствии с n8n configuration | Конфигурационный diff без секретов и негативный test |
| Environment / file access | Ограничить доступ workflow к environment и файловой системе по принципу наименьших привилегий | Redacted config и test разрешённых/запрещённых операций |
| Node allow/block policy | Заблокировать неразрешённые и опасные nodes; policy должна быть explicit | Список разрешённых/заблокированных nodes, validation export |
| Community nodes | Не устанавливать и не включать без отдельного supply-chain review и approval | ADR/review evidence либо отсутствие community nodes |
| Execution pruning | Настроить retention/pruning с учётом audit, storage и recovery | Redacted policy, restore/retention check |
| Telegram webhook | При `setWebhook` использовать `secret_token` и минимальный `allowed_updates` для workflow | Redacted request/config и received-header validation; token не сохранять |

Основные источники: [n8n SSRF protection](https://github.com/n8n-io/n8n-docs/blob/main/docs/deploy/host-n8n/configure-n8n/basic-configuration/use-environment-variables/ssrf-protection.md), [block specific nodes](https://github.com/n8n-io/n8n-docs/blob/main/docs/deploy/host-n8n/configure-n8n/security/block-specific-nodes.md), [execution data/pruning](https://github.com/n8n-io/n8n-docs/blob/main/docs/deploy/host-n8n/configure-n8n/scaling/manage-execution-data.md), [Telegram setWebhook](https://core.telegram.org/bots/api#setwebhook).

## Acceptance gates

- [ ] Завершён read-only VPS discovery; подтверждены ОС, ресурсы, занятые порты и отсутствие конфликтов.
- [ ] Exact immutable image digests и совместимость n8n/PostgreSQL/Caddy/runner зафиксированы отдельным evidence.
- [ ] Proxy topology подтверждает `N8N_PROXY_HOPS=1`; public URLs проходят HTTPS webhook/editor checks.
- [ ] Экспорт workflow подтверждает все пять node targets и их версии либо документирует безопасные замены.
- [ ] DeepSeek live spike подтверждает выбранный model ID, tool calling, thinking mode и обработку отсутствующего/неожиданного `reasoning_content`.
- [ ] Controls SSRF/env/file/nodes/community/pruning и Telegram webhook проверены без записи секретов.
