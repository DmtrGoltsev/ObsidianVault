### Фактическая архитектура

- OpenClaw — единственный вход Telegram через долгий опрос и единственный диалоговый контур.
- DeepSeek выполняет языковой вывод; OpenClaw сохраняет Markdown-память и SQLite-сессию. Сохранение после перезапуска проверено.
- Плагин `n8nagents-actions` версии `0.2.0` предоставляет пять инструментов напоминаний и ровно тринадцать инструментов Poruchik.
- Ровно два процесса Poruchik Wave 4 активны и имеют активную версию.
- Готовность после перезапуска подтверждается не только состоянием контейнера, но и отдельным подписанным запросом списка задач с ответом HTTP `200`.
- Инструменты обращаются к закрытому HMAC-подписанному программному интерфейсу действий n8n: процесс `ActionAPI0000001`, версия `83bd9d8b-278c-4dd1-ad7a-3e7cac9edb69`, путь `/internal/actions/v1`.
- PostgreSQL — источник истины для задач, напоминаний, подтверждений, повторов и аудита.
- Плановые отправки выполняют два процесса n8n: `SchedMatFresh001` версии `2347cf7a-5880-496e-a4c1-3243d641d47c` и `SchedConfFresh01` версии `d0634147-5bf7-49c8-84cc-cd6c910b64f7`.
- Их вызывают активные таймеры `n8nagents-scheduler@materializer.timer` и `n8nagents-scheduler@confirmation.timer` через внутренние HMAC-подписанные HTTP-входы.
- Caddy возвращает `404` для внутренних Action API и путей планировщиков.
- Прежний основной процесс Telegram в n8n и старые планировщики неактивны.

### Безопасность

- Один разрешённый личный чат, без групп и новых получателей.
- OpenClaw не получает Docker socket, командную строку, браузер, общий доступ к файлам, SQL или произвольный HTTP-инструмент.
- Разрешены только пять инструментов напоминаний и тринадцать инструментов Poruchik; четырнадцать опасных возможностей явно запрещены.
- Не читай и не печатай `.env`, токены, ключи, секретные заголовки, идентификаторы пользователя/чата и содержимое сообщений.
- Не допускай одновременной работы двух получателей Telegram.
- При сбое останавливай только проблемный вход или таймер; сохраняй PostgreSQL, задачи и аудит.
