# Синтез исходной задачи владельца

## Проектный outcome

Создать и довести до работающего состояния N8NAgents: self-hosted персональный AI-помощник на n8n Community Edition, PostgreSQL, Telegram и DeepSeek, с контролируемыми tools, памятью, backup/restore, monitoring, security gates и документацией в Obsidian.

## Запрос текущего цикла

1. Использовать **только план A: Docker Desktop локально на Windows**.
2. Не подтверждать и не применять план B — отдельную Ubuntu в WSL — как резерв. При проблеме искать другой путь и возвращаться к владельцу с доказательствами.
3. Сделать локальную среду постоянной и пригодной для большой последующей работы, а не удалять после одной задачи.
4. Обеспечить реальный локальный запуск n8n, PostgreSQL и отдельного Telegram dev/test bot как агентом, так и владельцем вручную.
5. Поддержать безопасный локальный Telegram path без публичного production endpoint.
6. До установки и реальных действий создать **полный** canonical plan.
7. Передать один frozen plan с исходной задачей и известным локальным/VPS/repo context десяти отдельным независимым reviewer agents с задачей дать максимум критики.
8. Проверить критику по кворуму и показать владельцу общую картину; только после этого владелец решит, переделывать ли план и разрешать ли исполнение.
9. Не ограничивать оркестрацию числом три. В текущем review cycle требуется ровно десять независимых reviewers, а будущая топология определяется задачей и доступным параллелизмом.

## Явные ожидания владельца

- План должен подробно объяснить реальный результат, действия, риски, изменения Windows, rollback, ручной сценарий и границы автоматизации.
- Пользователь должен уметь сам запустить/остановить лабораторию и провести реальный тест через Telegram.
- Секреты не передаются в review bundle, Vault или Git.
- До сведения критики реальных действий нет.
