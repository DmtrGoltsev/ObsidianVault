# Безопасность OpenClaw и n8n

## Основные угрозы

- сообщение прислал не владелец;
- злоумышленник повторно отправил старый подписанный запрос;
- модель попыталась вызвать неизвестный инструмент или передать лишние поля;
- секрет попал в журнал, Markdown или ответ пользователю;
- OpenClaw получил доступ к командной строке, файлам сервера или Docker;
- внутренний адрес n8n стал доступен из интернета;
- два процесса одновременно получают сообщения Telegram;
- действие выполнилось дважды после сетевой ошибки.

## Обязательные меры

### Входящие сообщения

- только один разрешённый пользователь и личный чат;
- группы и сообщения от имени каналов отклоняются;
- числовые идентификаторы берутся из доверенного контекста Telegram, а не из текста модели.

### Вызовы n8n

- HMAC-подпись;
- ограниченный срок действия;
- одноразовый номер для защиты от воспроизведения;
- строгая схема без лишних полей;
- идемпотентность;
- повторная проверка пользователя и чата;
- журнал результата без содержимого секретов.

### Контейнер OpenClaw

- файловая система только для чтения, кроме явно выделенных каталогов состояния;
- удалены все лишние возможности Linux;
- нет доступа к программному интерфейсу Docker;
- нет публичных портов;
- ограничены память, процессор и число процессов;
- запрещены командная строка, браузер, произвольная работа с файлами и общий сетевой инструмент.

### Секреты

- токены и ключи хранятся в закрытых файлах на сервере;
- права на секретные файлы — только владельцу;
- значения не выводятся в команды, журналы и доказательства;
- в Obsidian записываются только названия секретов и правила их использования.

## Отказы, которые считаются правильными

Система обязана отказать при неверной подписи, старом запросе, повторном одноразовом номере, неизвестном действии, лишнем поле, несовпадении пользователя или чата и попытке доступа к внутреннему адресу извне.

## Проверка перед принятием

Нужно подтвердить ограничения контейнера, отсутствие публичных портов, отказ неизвестному отправителю, отрицательные тесты Action API и единственного получателя сообщений Telegram.
