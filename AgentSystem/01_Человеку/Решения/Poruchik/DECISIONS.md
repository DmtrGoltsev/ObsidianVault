# Журнал решений Poruchik

Актуально на 7 сентября 2026 года.

## D-001 — прямой HTTP для личного MVP

**Решение:** после onboarding Android обращается к production по `http://154.59.110.121/` без VPN, WebSocket и постоянного SSH-туннеля.

**Причина:** владельцу нужна максимально простая работоспособная связь с любого Wi-Fi или мобильной сети; риск перехвата принят явно.

**Последствия:** меньше движущихся частей и проще восстановление связи. Транспорт не конфиденциален; bearer/session данные могут быть перехвачены сетью. HTTPS остаётся будущим усилением.

**Закрытые варианты:** IPv4/IPv6 SSH tunnel, SSH-over-WebSocket и VPN не являются текущим runtime-путём. Исторический код не должен определять новые решения.

## D-002 — push-first, HTTP-authoritative

**Решение:** доменные изменения пишут outbox; Task Core отправляет FCM data-сигнал; Android синхронизируется по HTTP и только затем отображает состояние.

**Причина:** обновления должны приходить без открытого приложения, а нажатие должно вести в точную задачу/диалог. FCM лучше соответствует Android lifecycle, чем постоянный сокет.

**Последствия:** WebSocket не нужен. Polling сохраняется как fallback. Push payload нейтрален и не является источником истины.

## D-003 — outbox, дедупликация и DLQ

**Решение:** V8 добавляет состояние dispatch; доставка устройству идемпотентна, имеет retry и DLQ.

**Причина:** сбой FCM не должен откатывать доменную транзакцию, а повтор publisher не должен создавать дубли.

**Последствия:** мониторить `ready`, `retry`, `dlq`; не удалять backlog без расследования.

## D-004 — последовательные офлайн-фазы

**Решение:** зависимые мутации отправляются после ответа на create и замены локального ID каноническим UUID.

**Причина:** отправка единого batch теряла status/result/cancel для ещё не существующего server ID.

**Последствия:** синхронизация медленнее одного batch, но сохраняет намерение и exactly-once.

## D-005 — ограниченный агент

**Решение:** OpenClaw работает с явным allowlist из 18 типизированных инструментов; filesystem/web/runtime/UI/agents/elevated/code mode запрещены.

**Причина:** агент не должен обходить Task Core, ACL, approval и audit.

**Последствия:** новая возможность требует схемы, n8n-маршрута, Action Executor/Task Core контракта и теста; одного изменения prompt недостаточно.

## D-006 — серверная истина вне OpenClaw memory

**Решение:** задачи, напоминания, approvals, audit и пользовательское доменное состояние хранятся в PostgreSQL. `USER.md` содержит только предпочтения, `MEMORY.md` — только подтверждённые долговременные факты.

**Причина:** файловая память модели не обеспечивает ACL, версии, транзакции и аудит.

## D-007 — постоянная подпись Android

**Решение:** релизы подписываются одним постоянным PKCS#12 keystore из резервного каталога; пароль вводится только локально и скрыто.

**Причина:** обновление Android требует того же сертификата; пароль не должен появляться в истории команд/чатов.

## D-008 — production E2E только в изолированном контуре

**Решение:** тест создаёт отдельные workspace/user/device/session, ведёт ledger и удаляет только созданные ID.

**Причина:** полное E2E на production необходимо, но данные владельца не должны изменяться.

## D-010 — документация не хранит секреты

**Решение:** в KB допустимы пути, имена переменных, публичные host/port, commit и hashes; недопустимы значения токенов, HMAC, Firebase service account, invite payload, private keys и пароли.

**Открытое действие:** явно исключить `N8NAgents/local/secrets/` из git и проверить историю/индекс по именам без вывода содержимого.
