## Rollback

- APK: сохранить предыдущий подписанный артефакт; откат приложения возможен только при совместимой схеме Room и versionCode.
- Backend: переключить на предыдущие неизменяемые image tags. Миграцию V8 не удалять и не откатывать разрушительно: старый код должен быть заранее проверен на совместимость с добавленными таблицами/статусом.
- Push: при проблеме отключить publisher конфигурационно, сохранить outbox и оставить HTTP polling fallback; не удалять pending-события вслепую.
- OpenClaw: откатить только package/runtime config на ранее проверенную версию, сохранив workspace и owner-сессии.

Любой rollback должен сопровождаться проверкой владельческих данных и отсутствия повторных побочных эффектов.
