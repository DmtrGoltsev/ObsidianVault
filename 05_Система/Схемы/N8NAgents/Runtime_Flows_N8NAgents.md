# Потоки выполнения N8NAgents

## Подтверждённая схема рабочего сервера

```mermaid
flowchart TB
    I[Интернет] -->|порт 443| C[Caddy]
    C -->|внутренняя сеть контейнеров| N[n8n]
    O[Оператор через SSH-туннель] -->|127.0.0.1:5678| N
    N -->|внутренняя сеть данных| P[(PostgreSQL)]
    N -->|разрешённые исходящие запросы| T[Telegram API]
    N -->|разрешённые исходящие запросы| D[DeepSeek API]
```

Порт n8n `5678`, PostgreSQL и программный интерфейс Docker не доступны из интернета. Административный доступ к n8n выполняется только через защищённый SSH-туннель.

## Обработка одного сообщения Telegram

```mermaid
sequenceDiagram
    participant T as Telegram
    participant C as Caddy
    participant N as n8n
    participant P as PostgreSQL
    participant D as DeepSeek
    T->>C: Защищённый входящий запрос
    C->>C: Проверка адреса, метода и секрета
    C->>N: Разрешённый запрос
    N->>N: Проверка отправителя и повтора
    N->>P: Загрузка истории доверенной сессии
    N->>D: Ограниченный запрос к модели
    D-->>N: Ответ модели
    N->>P: Сохранение истории этой сессии
    N->>T: Один ответ исходному получателю
```

Подтверждённое правило: одно входящее сообщение создаёт одно завершённое выполнение и не более одного исходящего ответа.

## Действия при ошибке

```mermaid
flowchart LR
    A[Обнаружена ошибка] --> B[Остановить только проблемный вход]
    B --> C[Сохранить базу, тома и предыдущую версию]
    C --> D[Найти причину без раскрытия секретов]
    D --> E[Внести минимальное исправление]
    E --> F[Проверить ошибочный и обычный случаи]
    F --> G[Развернуть с возможностью отката]
    G --> H[Повторно проверить рабочий сервер]
    H --> K[Обновить документацию]
```

Запрещено удалять тома или данные для сокрытия ошибки. При размножении ответов входящий поток останавливается до выяснения причины.

## Правило обновления

Схема меняется только по свежим доказательствам с рабочего сервера. Планируемая архитектура хранится отдельно.
