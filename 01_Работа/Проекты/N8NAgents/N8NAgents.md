# N8NAgents

## Цель

Безопасно спроектировать и развернуть self-hosted персонального AI-помощника на базе n8n Community Edition на VPS. Интерфейс — Telegram; LLM — DeepSeek; хранилище metadata, памяти и прикладных данных — PostgreSQL.

## Стек

| Слой | Планируемые технологии |
|---|---|
| Оркестрация | n8n Community Edition |
| Развертывание | Docker Compose |
| Reverse proxy | Caddy |
| Данные | PostgreSQL |
| Интерфейс | Telegram Bot |
| LLM | DeepSeek API |

## Текущий статус

Инициализация документации завершена. Фактическое состояние VPS и совместимость версий пока не подтверждены.

## Окружения

- Локальное: только SSH-preflight.
- VPS: доступ, порт и SSH host fingerprint не подтверждены.
- Production: не начат.

## Активные гейты

1. Разрешён только локальный SSH-preflight.
2. SSH-подключение запрещено до независимого подтверждения фактического порта и ожидаемого SSH host fingerprint.
3. Любые изменения VPS запрещены до read-only discovery, подготовки архитектуры и явного approval пользователя.
4. Секреты не создаются и не сохраняются в vault, Git или отчетах.

## Известные риски

- Доступность и соответствие приватного SSH-ключа не подтверждены.
- Порт SSH из исходного промпта — предположение до независимой проверки.
- Неизвестны существующие сервисы, занятые порты и ресурсы VPS.
- Не предоставлены обязательные non-secret параметры доменов, DNS, timezone, Telegram и backup-политики.
